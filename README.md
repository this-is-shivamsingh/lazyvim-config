# lazyvim-config

A portable LazyVim and Ghostty setup styled after Sublime Text's Mariana dark theme.

It includes:

- LazyVim configuration and locked plugin versions
- A local `mariana` Neovim colorscheme
- Ghostty colors, padding, and Consolas-for-Powerline font configuration

For a complete, repeatable setup, follow [instruction.md](instruction.md).
